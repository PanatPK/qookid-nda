# ฟอร์มสัญญาจ้างงานออนไลน์ (รวมแนวปฏิบัติและการรักษาความลับ) (QOOKID Creation)

## ไฟล์
- `index.html` หน้าที่ส่งให้สตาฟ กรอกข้อมูล อ่านสัญญา เซ็นชื่อ แล้วบันทึกเป็น PDF ได้
- `job.html` หน้าใบงานรายคน สตาฟเปิดจากลิงก์ส่วนตัวแล้วกดรับทราบ
- `jobs.js`, `store.js` ระบบใบงานและการจ่ายเงินในหน้าแอดมิน
- `admin.html` หน้าแอดมิน ดูรายชื่อผู้ลงนาม เปิดดู/พิมพ์สัญญาแต่ละฉบับ ดาวน์โหลด CSV และสร้างลิงก์ตามชื่องาน
- `contract.js` ข้อความสัญญาและค่าตั้งต้น (ชื่อบริษัท ผู้ลงนามฝั่งบริษัท กำหนดจ่ายเงิน เวลามาก่อนงาน ระยะเวลาผูกพัน ค่าปรับ ประเภทพนักงาน)
- `style.css` หน้าตาและรูปแบบตอนพิมพ์ A4
- `firestore.rules` กฎความปลอดภัยของ Firestore
- `config.sample.js` ตัวอย่างไฟล์ตั้งค่า Firebase

ถ้ายังไม่มี `config.js` ทั้งสองหน้าจะทำงานในโหมดทดลอง เก็บข้อมูลไว้ในเบราว์เซอร์เครื่องนั้น

## ติดตั้ง
1. Firebase Console สร้างโปรเจกต์ (หรือใช้โปรเจกต์เดิม) เปิด Firestore Database
2. Authentication > Sign-in method เปิด Email/Password แล้วเพิ่มผู้ใช้แอดมิน
3. แก้อีเมลใน `firestore.rules` ให้ตรงกับบัญชีแอดมิน แล้ววางกฎใน Firestore > Rules
   (ถ้าใช้โปรเจกต์ร่วมกับระบบอื่น ให้รวมเฉพาะส่วน `nda_signatures` เข้าไปในกฎเดิม)
4. คัดลอก `config.sample.js` เป็น `config.js` ใส่ค่า Web app config
5. อัปโหลดทุกไฟล์ขึ้น GitHub repo แล้วเปิด GitHub Pages
6. Authentication > Settings > Authorized domains เพิ่ม `panatpk.github.io`

## เอกสารแนบ
- สตาฟต้องแนบสำเนาบัตรประชาชนและหน้าสมุดบัญชี (รับไฟล์รูปหรือ PDF โดย PDF ใช้เฉพาะหน้าแรก)
- ระบบย่อรูป ใส่ลายน้ำ "ใช้สำหรับ QOOKID Creation เท่านั้น" และประทับ "สำเนาถูกต้อง" พร้อมลายเซ็น แล้วเก็บในคอลเลกชัน `nda_files`
- เก็บใน Firestore แทน Firebase Storage เพราะ Storage ต้องใช้แพ็กเกจ Blaze
- หน้าแอดมิน กด "ดูสัญญา" จะเห็นเอกสารแนบใต้สัญญา ดาวน์โหลดเป็น JPG ได้ และพิมพ์ออกมาต่อท้ายสัญญาหน้าละ 1 ไฟล์

## ใช้งาน
- ส่งลิงก์ `index.html` ให้สตาฟ หรือสร้างลิงก์ระบุชื่องานจากหน้าแอดมิน เช่น `index.html?project=TEAPOT`
- ระบุประเภทล่วงหน้าได้ด้วย `&type=สตาฟอีเวนต์`
- ฉบับที่เซ็นแล้วเก็บข้อความสัญญา ณ วันที่เซ็นไว้ด้วย ถ้าแก้ `contract.js` ภายหลัง ฉบับเก่าจะไม่เปลี่ยน (ให้เปลี่ยน `version` ทุกครั้งที่แก้ข้อความ)

## ใบงานและการจ่ายเงิน
1. หน้าแอดมิน แท็บ "ใบงานและการจ่ายเงิน" สร้างงาน (ชื่อ สถานที่ วันที่ จ่ายครั้งเดียวหรือ 2 งวด ภาษี %)
2. เพิ่มทีมงานจากรายชื่อที่เซ็นสัญญาแล้ว ใส่ตำแหน่ง เรทต่อวัน วันแรก-วันสุดท้ายของแต่ละคน และรายการเพิ่ม/หัก
3. กด "คัดลอกลิงก์" ส่งให้สตาฟ สตาฟเปิดดูใบงานของตัวเองแล้วกดรับทราบ
4. ถ้าแก้ตำแหน่ง เรท วันที่ หรือรายการเพิ่ม/หักหลังสตาฟกดรับทราบ สถานะจะกลับเป็น "รอรับทราบ" ให้ส่งลิงก์เดิมให้กดใหม่
5. หลังจบงาน ถ้ามีคนขาดให้ปรับวันที่หรือใส่รายการหัก แล้วกด "CSV สำหรับโอน" ได้ชื่อบัญชี ธนาคาร เลขบัญชี และยอดโอนของแต่ละคน
6. ติ๊กช่องยอดเงินเมื่อโอนแล้ว สตาฟจะเห็นสถานะ "โอนแล้ว" ในใบงาน
